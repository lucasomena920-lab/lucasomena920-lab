## Projetos em destaque

### 01 — WhatsApp Bot · Automação de atendimento

Sistema de atendimento automatizado com painel web para configuração
de mensagens e gestão da transição entre bot e atendimento humano.

- Configuração de respostas e menus através do painel.
- Acompanhamento do estado da conexão.
- Suspensão e reativação da automação por contacto.
- Integração atual via Baileys, com migração para a API oficial planeada.

**Stack:** TypeScript · Node.js · Baileys  
**Estado:** Em desenvolvimento

[Consultar repositório ↗](https://github.com/lucasomena920-lab/what-bot-test)

### 02 — Eclipse · Website de banda

Projeto web que combina apresentação musical, agenda de concertos
e funcionalidades de gestão de utilizadores e bilhetes.

- Páginas de álbuns, concertos e apresentação da banda.
- Estrutura de registo, autenticação e perfil de utilizador.
- Carrinho de bilhetes com persistência em localStorage.
- Acesso a dados através de PHP com PDO e MySQL.
- Fluxos de checkout e administração em integração.

**Stack:** HTML · CSS · JavaScript · Bootstrap · PHP · MySQL  
**Estado:** Em desenvolvimento

[Consultar repositório ↗](https://github.com/lucasomena920-lab/bandsa)
