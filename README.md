## Perfil profissional

Sou um profissional em início de carreira, com formação na área de
desenvolvimento de websites e desenho e interesse em desenvolvimento
web, automação e design de interfaces.

A minha base inclui HTML, CSS, JavaScript, PHP, SQL, AJAX e WordPress.
Nos projetos pessoais, também trabalho com TypeScript e Node.js,
explorando aplicações com painel web, gestão de dados e integração
com serviços externos.

Procuro compreender o funcionamento completo de uma aplicação:
a interface apresentada ao utilizador, a lógica que processa as ações
e a forma como os dados são organizados.

## Projetos em destaque

### 01 — WhatsApp Bot

**Automação de atendimento com painel web**

Sistema para configurar respostas automáticas e gerir a transição
entre atendimento por bot e atendimento humano.

- Configuração de mensagens e menus através do painel.
- Acompanhamento do estado da conexão com o WhatsApp.
- Encaminhamento para atendimento humano por contacto.
- Suspensão e reativação das respostas automáticas.
- Integração atual via Baileys, com migração para a API oficial planeada.

| :--- | :--- |
| **Tecnologias** | TypeScript · Node.js · Baileys |
| **Foco técnico** | Fluxos de mensagens, configuração por conta e estados de atendimento |
| **Estado** | Em desenvolvimento |

### 02 — Eclipse

**Website de banda com funcionalidades de gestão**

Projeto que reúne apresentação musical, lançamentos e agenda
de concertos, com uma base de funcionalidades para utilizadores
e gestão de bilhetes.

- Páginas de álbuns, concertos e apresentação da banda.
- Estrutura de registo, autenticação e perfil de utilizador.
- Carrinho de bilhetes com persistência em localStorage.
- Acesso à base de dados através de PHP com PDO.
- Fluxos de checkout e administração em integração e validação.
